# Les couvertures des coups de cœur de La Page d'Alice

Ce dossier reçoit les couvertures des huit livres conseillés par la librairie
de démonstration (`comptoir-librairie` dans `src/lib/direct/apercu-habitant.ts`).
Le code les attend à ces adresses exactes. Tant qu'un fichier manque, la
couverture dessinée au titre du livre s'affiche à sa place : rien ne casse.

| Fichier                 | Livre                                                  |
|-------------------------|--------------------------------------------------------|
| `anomalie.png`          | L'Anomalie — Hervé Le Tellier (Folio)                  |
| `harry-quebert.jpg`     | La Vérité sur l'affaire Harry Quebert — Joël Dicker    |
| `gratitudes.jpg`        | Les Gratitudes — Delphine de Vigan                     |
| `sapiens.jpg`           | Sapiens — Yuval Noah Harari                            |
| `blacksad.jpg`          | Blacksad, tome 1 — Canales et Guarnido                 |
| `petit-prince.jpg`      | Le Petit Prince — Antoine de Saint-Exupéry             |
| `ottolenghi-simple.png` | Simple — Yotam Ottolenghi                              |
| `monte-cristo.jpg`      | Le Comte de Monte-Cristo — Alexandre Dumas             |

## Ce qui rend bien

- La couverture de face, droite, sans fond autour.
- Format portrait, environ 600 points de haut.
- En JPG ou PNG, et le nom de fichier exactement comme dans le tableau (minuscules,
  tirets, extension comprise).
- De préférence les visuels « presse » des éditeurs, faits pour cet usage.
